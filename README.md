# Доска домашних заданий — МУКР

Статический сайт на GitHub Pages: что задали по каждому предмету.
Смотреть может любой, у кого есть ссылка. Записывает только староста.

## Как записать задание

Есть два пути.

**1. Прямо на сайте.** Кнопка «Староста» → вставить personal access token →
у каждого предмета появятся кнопки «Записать» / «Изменить».
Токен хранится только в браузере старосты (localStorage) и никуда больше не уходит.

Токен нужен fine-grained, на этот один репозиторий, с правом
**Contents: Read and write**: https://github.com/settings/personal-access-tokens/new

**2. Вручную.** Открыть `homework.json` на GitHub и отредактировать карандашом.

## Где лежат данные

Всё в `homework.json`:

```json
{
  "subjects": {
    "matematika": { "text": "№ 145-150", "due": "2026-09-24", "updated": 1758300000000 }
  },
  "updated": 1758300000000
}
```

Сайт читает файл через GitHub API, поэтому запись видна сразу, без ожидания пересборки Pages.
