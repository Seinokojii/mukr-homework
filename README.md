# Доска домашних заданий — МУКР

Статический сайт на GitHub Pages: что задали по каждому предмету.
Смотреть может любой, у кого есть ссылка: **https://seinokojii.github.io/mukr-homework/**
Записывает только староста — по паролю, который знает он сам.

## Как это работает

GitHub Pages — статика, проверить пароль на сервере негде. Поэтому пароль
не сравнивается с эталоном, а **расшифровывает** ключ записи:

1. Токен GitHub шифруется паролем (PBKDF2-SHA256, 200 000 итераций → AES-256-GCM)
   и лежит в репозитории как `token.enc`.
2. Староста вводит пароль → браузер расшифровывает токен у себя → пишет им в
   `homework.json` через GitHub Contents API.
3. Неверный пароль не расшифровывает ничего: в `token.enc` для чужого остаётся
   бесполезный шифртекст.

Токен живёт только в памяти вкладки (sessionStorage) и пропадает при её закрытии.
В открытом виде он не хранится нигде в репозитории.

## Настройка ключа записи (один раз)

1. Создать fine-grained токен: https://github.com/settings/personal-access-tokens/new
   - Repository access → Only select repositories → `mukr-homework`
   - Permissions → Contents → **Read and write**
2. Запустить и вставить токен по запросу:

```bash
python3 set-token.py
```

Скрипт зашифрует токен паролем из переменной `PASSWORD` в самом скрипте,
положит `token.enc` и отправит на GitHub. Сменить пароль — поправить
`PASSWORD` и запустить снова.

## Где лежат данные

Всё в `homework.json`:

```json
{
  "subjects": {
    "matematika": { "text": "№ 145-150", "due": "2026-09-24", "updated": 1758300000000 }
  },
  "updated": 1758300000000
}
```

Файл читается через GitHub API, поэтому запись видна сразу, без ожидания
пересборки Pages. Задание можно править и вручную — карандашом прямо на GitHub.
